# Phase 02.1 Plan 06: Owner-Draw Menu + Custom Status Footer Summary

Owner-draw View menu (D-03) and custom-painted FileTreeStatusFooter (D-07) wired into the Win32 message loop, closing POL-03 mnemonic underline behavior.

## What Was Built

### Task 1 (committed 8c381be — prior session)

**ffi.rs:** Added `WM_UPDATEUISTATE`, `WM_CHANGEUISTATE`, `UIS_SET/CLEAR/INITIALIZE`, `DT_HIDEPREFIX`, `ODT_MENU`, `ID_STATUS_FOOTER = 115`, `STATUS_FOOTER_CLASS_NAME = "FileTreeStatusFooter"`, `DrawMenuBar` to User32 extern block.

**paint.rs:**
- `menu_item_colors(item_state, dark, accent, selected_text) -> (fg, bg)` — pure fn, ODS_DISABLED / ODS_SELECTED|ODS_HOTLIGHT / normal state machine
- `draw_menu_item(dis, label, checked, mnemonics_visible, state)` — fills bg, draws checkmark glyph if checked, renders label with DT_HIDEPREFIX when mnemonics hidden
- `draw_status_footer(hwnd, state)` — double-buffered paint: palette_panel bg, 1px palette_line top hairline, 5 panes via format_status_* helpers
- `status_footer_window_proc()` — WM_PAINT calls draw_status_footer, WM_ERASEBKGND returns 1
- `register_status_footer_class()` — OnceLock-idempotent RegisterClassW
- 5 unit tests for menu_item_colors covering all ODS state combinations

### Task 2 (committed 642ab35 — this session)

**ffi.rs:** Added `GetMenu` to User32 extern block.

**state.rs:** Added `status_footer: Hwnd` and `ui_state: Uint` fields to DesktopState; initialized `status_footer = 0`, `ui_state = UISF_HIDEACCEL`.

**theme.rs:** Removed `SetWindowTheme(state.status, ...)` call (msctls_statusbar32 removed).

**mod.rs:**
- `apply_menu_bg(menu, dark)` helper: SetMenuInfo with MIM_BACKGROUND using dark_brush/light_brush
- Converted all `AppendMenuW` calls to `MF_STRING | MF_OWNERDRAW` (3 items) and `MF_POPUP | MF_OWNERDRAW` (top-level &View)
- `apply_menu_bg()` called on main_menu + view_menu after SetMenu in create_controls
- `WM_MEASUREITEM` arm: 22 logical px height (DPI-scaled) for MF_OWNERDRAW items
- `WM_DRAWITEM` arm: recovers label from itemData pointer, calls `paint::draw_menu_item` with mnemonics_visible gate
- `WM_UPDATEUISTATE` arm: syncs `state.ui_state` bits, propagates to DefWindowProcW
- `WM_CHANGEUISTATE` init in `run()` before ShowWindow: `MAKEWPARAM(UIS_SET, UISF_HIDEACCEL)`
- `ID_VIEW_DARK_MODE` handler: re-calls `apply_menu_bg` + `DrawMenuBar` on toggle
- `resize_controls`: replaced `SendMessageW(state.status, ...)` pane layout with `MoveWindow(state.status_footer, ...)` at 22px height; `panel_h` now subtracts `footer_h` (was `status_h`)
- All `state.status` / `set_status_pane` call sites replaced with `InvalidateRect(state.status_footer, ...)` — footer auto-paints from state fields
- msctls_statusbar32 creation removed; `register_status_footer_class + CreateWindowExW` for FileTreeStatusFooter
