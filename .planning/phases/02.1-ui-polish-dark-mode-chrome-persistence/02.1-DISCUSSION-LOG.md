## Dark mode

**Q:** Strategy — undocumented Win10/11 APIs vs full owner-draw vs hybrid?

**Options:** undoc-first + owner-draw fallback (recommended) / full owner-draw / hybrid (replace problematic controls).

**User:** Undoc APIs first, owner-draw only where they fail.

→ **D-03.** Resolve uxtheme ordinals 132/133/135/136 via GetProcAddress with null-check; owner-draw the menu bar + status bar only.

**Q:** Timing of dark-mode apply + palette source?

**Options:** apply early + system accent (recommended) / apply early + fixed palette / auto-follow system theme.

**User:** Apply early + system accent.

→ **D-04** (no first-paint flash) + **D-05** (DwmGetColorizationColor accent + tuned dark grayscale).

## Toolbar removal & layout

**Q:** Where do the Hidden / Files / Dark toggles go?

**Options:** View menu checkable items (recommended) / View menu + auto-defaults / drop menu entirely.

**User:** View menu — checkable items.

→ **D-06.** Delete the current toolbar row; toggles become MF_CHECKED menu items synced via WM_INITMENUPOPUP.
