<objective>
Land the Bootstrap Icons binary asset, register it at process startup via `AddFontMemResourceEx`, and expose a single-source-of-truth glyph module (`src/desktop/icons.rs`) with named codepoint constants and a `draw_icon` helper. This is foundational for Plan 02.1-04 (tabs window class) and 02.1-06 (owner-draw menu checkmark).

Purpose: Eliminates hard-coded magic glyph literals anywhere in the codebase; gives the executor a typed API (`ICON_LIST_NESTED`, `draw_icon(...)`) instead of `'\u{F4A6}'` everywhere. Per D-01 + D-02, glyphs render at any DPI with zero decoder code via GDI's `DrawTextW`. Plan also delivers POL-03 prerequisite — Bootstrap Icons supplies the ALT-mnemonic accent glyphs (`UISF_HIDEACCEL` paint paths in Plans 02.1-05/06 depend on the icon font being registered before any menu/strip paints).

Output: Committed TTF asset + assets/README.md (source URL + commit SHA + SHA-256 + MIT license note) + new module `src/desktop/icons.rs` + FFI declaration for `AddFontMemResourceEx` in `src/desktop/ffi.rs` + a single call site in `src/desktop/mod.rs::run` before first paint + NOTICE entry.

This plan is `autonomous: false` because Task 1 requires the developer to download the v1.11.3 `.ttf` from GitHub (a `checkpoint:human-action` — there is no CLI to fetch a GitHub release asset that we can rely on offline).
</objective>
