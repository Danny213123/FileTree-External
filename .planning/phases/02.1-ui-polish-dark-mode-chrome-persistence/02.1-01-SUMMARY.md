# Phase 02.1 Plan 01: Bootstrap Icons font asset + icons.rs module Summary

**One-liner:** Bootstrap Icons v1.11.3 TTF embedded via `include_bytes!`, registered at startup via `AddFontMemResourceEx` with 6 named codepoint constants and a `draw_icon` GDI helper.

## What Was Built

Task 1 (TTF asset + provenance) was already completed in commit `ddf30b9` on the base branch prior to this execution wave. This execution covered Task 2 only.

**Task 2 — icons.rs module + FFI + call site** (commit `2dd3ca0`):

- **`src/desktop/icons.rs`** (new, 146 lines): Single source of truth for Bootstrap Icons codepoints. Contains:
  - `ICON_FONT_BYTES: &[u8] = include_bytes!("../../assets/bootstrap-icons-1.11.3.ttf")` — static lifetime in .exe read-only segment (T-02.1-01-02 mitigation)
  - `ICON_FONT_HANDLE: OnceLock<isize>` — process-lifetime registration handle
  - 6 `pub(super) const ICON_*: char` codepoint constants (verified against bootstrap-icons.css v1.11.3)
  - `pub(super) const ICON_FONT_FAMILY: &str = "bootstrap-icons"`
  - `pub(super) fn register_icon_font()` — OnceLock-idempotent, calls `AddFontMemResourceEx`
  - `pub(super) unsafe fn draw_icon(hdc, x, y, codepoint, size_px, color)` — one-shot HFONT via `CreateFontIndirectW` + `DrawTextW`, `DeleteObject` on exit

- **`src/desktop/ffi.rs`** (modified): Added to Gdi32 link block: `AddFontMemResourceEx` (4-param signature per Win32 docs), `CreateFontIndirectW`. Added `LOGFONTW` struct (repr(C), 13 fields matching Win32 layout). Added constants: `DEFAULT_CHARSET`, `OUT_DEFAULT_PRECIS`, `CLIP_DEFAULT_PRECIS`, `DEFAULT_QUALITY`, `DEFAULT_PITCH`, `FW_NORMAL`, `DT_TOP`.

- **`src/desktop/mod.rs`** (modified): Added `mod icons;` declaration. Inserted `icons::register_icon_font()` call after `RegisterClassW(&window_class)` and before `CreateWindowExW` — the one call site per plan spec.
