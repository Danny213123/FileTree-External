    **MODE 1 — `scan` CLI parity (cross-platform; required)**

    Pick a stable, mid-sized target. Recommended: `C:\Windows\Logs` on Windows (typically 50-500 MB, several thousand files, includes some access-denied subfolders to exercise `ScanError` handling). On non-Windows or if `C:\Windows\Logs` is unavailable, substitute a similarly-sized stable directory.

    BEFORE Phase 1 (if not already done — run from the `v0.1.0` tag or a commit before extraction started):
    ```
    cargo build --release
    .\target\release\filetree.exe scan C:\Windows\Logs --format json --out baseline.json
    .\target\release\filetree.exe scan C:\Windows\Logs --format csv  --out baseline.csv
    ```

    AFTER Phase 1 (current HEAD):
    ```
    cargo build --release
    .\target\release\filetree.exe scan C:\Windows\Logs --format json --out after.json
    .\target\release\filetree.exe scan C:\Windows\Logs --format csv  --out after.csv
    ```

    Comparison checks (per RESEARCH §"Smoke-Test Recipe" Mode 1):
    1. `(Get-Item baseline.json).Length` is within a few bytes of `(Get-Item after.json).Length` (the legitimate diff is `scanned_at_ms` and `elapsed_ms`).
    2. Top-10 directories by size match between `baseline.json` and `after.json`.
    3. Total file count and folder count match exactly.
    4. The `errors` array length matches exactly.
    5. `diff baseline.csv after.csv` shows only timestamp drift (if any).

    **MODE 2 — `serve` HTTP server parity (cross-platform; required)**

    Terminal A:
    ```
    .\target\release\filetree.exe serve --path C:\Windows\Logs --port 7878
    ```

    Terminal B (RESEARCH §"Smoke-Test Recipe" Mode 2):
    ```
    curl -s http://127.0.0.1:7878/api/config
    # Expect: {"version":"0.1.0","initialPath":"C:\\Windows\\Logs"}

    curl -s http://127.0.0.1:7878/api/drives
    # Expect: a JSON array of drive entries on Windows; structurally identical to v0.1.0

    curl -s "http://127.0.0.1:7878/api/scan?path=C:\Windows\Logs&threads=4" > scan-api.json
    # Spot-check scan-api.json contains: nodes (array), errors (array), root_path (string),
    # scanned_at_ms (number), elapsed_ms (number), thread_count (number)

    curl -s "http://127.0.0.1:7878/api/export.csv" > export-api.csv
    diff after.csv export-api.csv
    # Expect: near-identical (allow timestamp drift)

    curl -s "http://127.0.0.1:7878/api/export.json" > export-api.json
    # Spot-check structurally matches after.json
    ```

    Then open `http://127.0.0.1:7878/` in a browser (any modern Chromium/Firefox/Edge). Verify:
    - Tree renders with size bars and percentages
    - Treemap renders (recursive binary-split layout)
    - Extensions tab renders the extension stats
    - Top tab renders the largest files
    - Duplicates tab renders the duplicate candidates
    - Errors tab renders any access-denied entries
    - The "Exact hash scan" button on the Duplicates tab triggers `/api/duplicates` and re-renders without error

    **MODE 3 — `desktop` native Win32 parity (Windows-only; required if on Windows)**

    ```
    .\target\release\filetree.exe desktop --path C:\Windows\Logs
    ```

    Visual + interactive checks (RESEARCH §"Smoke-Test Recipe" Mode 3):
    1. Window opens with the toolbar tabs (File / Home / Scan / View / Options / Help) visible
    2. Path bar is pre-filled with `C:\Windows\Logs`
    3. "Scan" button triggers a scan; status bar updates with progress approximately every 1.5 seconds (the 1500 ms progress cadence from PROJECT.md must be preserved)
    4. Tree populates with sortable columns: Name, Size, Allocated, Files, Folders, %, Modified
    5. Twist arrows expand and collapse directories
    6. "Stop" cancels an in-flight scan; status returns to idle within ~1.5 seconds (cancel token plumbing via `Arc<AtomicBool>` is preserved)
    7. Dark-mode toggle flips the palette across all controls (every `palette_*` function in `desktop/theme.rs` is invoked correctly)
    8. Right-click on a row shows the Windows Shell context menu (Open, Properties, etc.) — this exercises the IShellFolder/IContextMenu COM vtable code in `desktop/shell.rs`
    9. Double-click on a directory expands it; double-click on a file invokes `ShellExecuteW open` (opens in default handler)
    10. Window resize re-flows all controls without flicker (`resize_controls` + GDI double-buffering in `desktop/paint.rs` work correctly)
    11. **Pitfall 3 canary:** No black console window appears alongside the native window — confirms the `#![cfg_attr(not(debug_assertions), windows_subsystem = "windows")]` attribute stayed at line 1 of `src/main.rs` (per Plan 01 Task 7)
