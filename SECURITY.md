# Security Policy

FileTree scans local file systems and can open or reveal files through the operating system shell. Please report security issues privately before posting public details.

## Reporting

Use GitHub private vulnerability reporting if it is enabled for the repository. If it is not enabled, contact the maintainer through the GitHub repository owner profile and include:

- Affected version.
- Steps to reproduce.
- Expected and actual behavior.
- Any relevant logs or screenshots.

## Supported Versions

Only the latest released version is supported while the project is pre-1.0.
